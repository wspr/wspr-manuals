\section{Introduction}

This manual includes everything you need to know about running a research project with Will.

\section{Cloud and Files}

\begin{enumerate}
\item Will will create a MS Teams channel for the project. Use OneDrive to sync the files from this channel to your Mac/PC and use it as the working folder and archive for the project.
\end{enumerate}

\section{Software}

\begin{enumerate}
\item CAD --- please use the browser-based Onshape software. Will will add you to his team there so you can browse and re-use designs.
\item Reports --- please use Overleaf and write your documents in LaTeX. Although perhaps a learning curve for some of you, it will pay dividends. Will can help solve almost any LaTeX problem and is happy to help.
\end{enumerate}
